# Wilson Lim — Portfolio

A responsive, skeuomorphic portfolio for Wilson Lim, built with React, Vite, and Anime.js.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site is configured for the `/Portfolio/` GitHub Pages base path. Run `npm run deploy` for a manual deployment, or push to `main` to use the included GitHub Actions workflow.

## Updating portfolio content

Projects, capabilities, and credentials are maintained in `src/data/portfolio.js`. Add verified project descriptions, outcomes, links, and screenshots there without changing the presentation components.
